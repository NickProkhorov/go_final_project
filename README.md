
# 🗓 Go Final Project — Планировщик задач (TODO-лист)

## 📘 Описание проекта
Дипломный проект курса **«Go-разработчик» (Яндекс.Практикум)**.  
Проект представляет собой веб-сервер, реализующий REST API для планировщика задач — аналога TODO-листа.

Пользователь может:
- добавлять задачи с датой и правилом повторения (`d N`, `y`);
- просматривать список ближайших задач;
- редактировать, удалять и отмечать задачи выполненными;
- взаимодействовать с веб-интерфейсом через HTML/JS фронтенд, подключённый к API.

Все данные сохраняются в базе **SQLite** (файл `scheduler.db` создаётся автоматически при первом запуске).

---

## ⭐ Задачи проекта
Задания повышенной сложности **не выполнялись**.  
Реализованы только обязательные функции:
- добавление задач;
- получение списка;
- редактирование;
- отметка о выполнении;
- удаление задач;
- базовые правила повторения (`d N` и `y`).

## ⚙️ Инструкция по запуску кода локально

### 1. Клонирование проекта

```bash
git clone https://github.com/NickProkhorov/go_final_project.git
cd go_final_project
```

---

### 2. Настройка окружения

Создайте файл .env в корне проекта c содержаением: 
```bash
TODO_PORT=7540
TODO_DBFILE=./scheduler.db
```
Если файл не создан, используются значения по умолчанию:
порт — 7540;
база данных — scheduler.db в корне проекта.

Установите зависимости, выполнив команду **go mod tidy** в корне проекта.
Запустите сервер с помощью команды **go run main.go**
Откройте в браузере адрес: http://localhost:7540


## ⚙️ Инструкция по запуску тестов

### 1. Запуск всех тестов: 
```bash
go test ./tests
```

### 2. Запустить атомарные тесты: 
```bash
go test -run ^TestAddTask$ ./tests
go test -run ^TestTasks$ ./tests
go test -run ^TestTask$ ./tests
go test -run ^TestEditTask$ ./tests
go test -run ^TestDone$ ./tests
go test -run ^TestDelTask$ ./tests
```
